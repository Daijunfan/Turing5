# MORPH-N 理论结果

## 记号

架构集为有限集合 `H`，任务字母表为有限集合 `Σ`。初始代价向量为 `α∈(Q∪{∞})^H`。字母 `a` 的迁移和服务合并为：

`M_a[p,q] = d_a(p,q) + c_a(q)`。

向量递推为：

`V_ε=α`，

`V_wa(q)=min_p(V_w(p)+M_a[p,q])`，

`F(w)=min_q V_w(q)`。

所有实现使用 `Fraction` 或整数；`∞` 是 `None`，不是大整数哨兵。C++ 独立 smoke checker 使用显式 `INF`，但其结论不参与 Python 证书中的等价判断。

## 定理一：动态形态系统到 min-plus WFA 的严格归约

**状态：已严格纸面证明，并由显式穷举验证。**

给定任意任务词 `w=a₁…a_T` 和架构轨迹 `h₀…h_T`，定义轨迹代价：

`α(h₀)+Σ_{t=1..T}[d_{a_t}(h_{t-1},h_t)+c_{a_t}(h_t)]`。

把架构作为 WFA 状态、任务作为输入字母、边权设为 `M_a`。该 WFA 在 `w` 上每条运行与一条架构轨迹一一对应，且运行权恰等于轨迹代价。WFA 的 tropical 加法取所有运行权的最小值，所以其词值等于动态形态离线最优。

**证明。** 对词长归纳。空词时到状态 `q` 的最小权为 `α(q)`。若 `V_w(p)` 已等于所有以 `p` 结尾轨迹的最小代价，追加 `a` 和终态 `q` 时，最后一条边必须来自某个 `p`，故最小代价为 `min_p[V_w(p)+M_a[p,q]]`。再对终态取最小得到 `F(wa)`。证毕。

这一定理是标准 min-plus WFA 语义的应用，不是发明加权自动机。

## 定理二：相同规范化残差决定全部未来增量

定义 `ρ_w(q)=V_w(q)-F(w)`，有限坐标整体减去最小值，`∞` 保持 `∞`。

**状态：已严格纸面证明；Lean 文件存在，但工具链下载失败，所以不称为机器证明。**

若 `ρ_u=ρ_v`，则对任意后缀 `z`：

`F(uz)-F(u)=F(vz)-F(v)`，

且逐字母最优成本增量流完全相同。

**证明。** min-plus 更新具有加法齐次性：对任意有限标量 `λ`，`T_a(x+λ·1)=T_a(x)+λ·1`。因此下一步的规范化结果和相对当前最小值的增量只由规范化输入 `ρ` 决定。对后缀长度归纳即可。证毕。

### 逆命题

未来行为等价不必推出残差向量相同。`counterexamples/growing_residual_closure.json` 的二状态单字母系统产生 `(0,t)`，但所有历史及未来的最优增量恒为 0；无限多个残差属于同一行为类。

逆命题成立的一个充分条件是“残差可观测”：对允许残差集合中的任意不同 `ρ,σ`，存在后缀 `z` 使两者的未来增量不同。这正是把残差映射到未来函数的映射为单射。持续矩阵更新的 14 状态实例不满足：218 个原始残差经精确 Mealy 分区细化只剩 56 个行为类。因此必须额外做行为商，不能把原始残差数当作 `|R|`。

## 定理三：有限列差推出残差闭包有限

**状态：已严格纸面证明并穷举验证；未完成 Lean 机器证明。**

设 `|H|=n`，所有 `M_a[p,q]` 都是有限整数。定义：

`Δ=max_{a,p,q,r}|M_a[p,q]-M_a[p,r]|`。

则读入至少一个字母后的任意可达规范化残差满足：

`0≤ρ(q)≤Δ`。

因而可达残差至多 `(Δ+1)^n` 个，再加可能含 `∞` 的初始残差；BFS 必然终止。

**证明。** 令 `p_r` 是 `T_a(V)(r)` 的一个最小前驱，则：

`T_a(V)(q)-T_a(V)(r)`

`≤V(p_r)+M_a[p_r,q] - [V(p_r)+M_a[p_r,r]]`

`≤Δ`。

交换 `q,r` 得绝对差不超过 `Δ`。规范化后最小坐标为 0，故每个整数坐标属于 `{0,…,Δ}`。有限笛卡尔积给出结论。证毕。

该条件非常强。带内存不可行边的矩阵含 `∞`，不能直接使用；二状态 `(0,t)` 反例说明删去有限性条件后闭包可无限增长。非约束预算的真实矩阵链模型所有边有限，14 状态实例的实际闭包为 218，远小于粗上界。

## 定理四：有限闭包控制器保持所有任务词的精确最优

**状态：已严格纸面证明、独立证书重放通过。**

若从初始残差出发的 BFS 队列清空，且每个残差对每个字母都有一条记录边 `(ρ,a,δ,ρ')`，构造确定 Mealy 控制器：

- 状态：可达残差；
- 转移：`ρ --a--> ρ'`；
- 输出：本步最优增量 `δ`。

则从初始值 `F(ε)` 开始累加控制器输出，对任意词 `w` 都得到 `F(w)`。

**证明。** 定理二表明每条记录边与 min-plus DP 的一步规范化完全一致。对词长归纳，控制状态等于 `ρ_w`，累计值等于 `F(w)`。证毕。

本项目的闭包证书有 218 状态、1090 转移、未处理状态 0；独立 checker 重新计算每条边和输出，并核对稳定哈希。

## 定理五：有限闭包下 MORPH-N 双循环有限终止

**状态：已严格纸面证明，显式实例验证。**

假设 `H,Σ` 有限，相关全系统与候选子系统的残差闭包有限，并且反例 oracle 完整。

1. 行为循环每遇到区分后缀就严格分裂一个 R 类，最多分裂到有限残差状态数；
2. 执行循环每遇到值不等价词，其全状态最优路径必含 `K` 外状态，否则同一路径在 K 中可行，产生矛盾；所以每轮至少加入一个新架构，最多加入 `|H|` 次；
3. 两个循环的字典序势函数“未分裂行为对数＋未加入架构数”严格下降，故有限终止；
4. 终止时不存在区分后缀和执行反例，有限控制器对所有词输出全状态最优；
5. 最后的逐状态删除每次重新验证全词等价，所以结果 K 是包含极小；
6. 包含极小不等于最小基数。若无全部子集 oracle 或复杂性证明，不得声称全局最小。

真实 14 架构实例得到 `|R|=56, |K|=4, |H|=14`。K 的全词等价由残差对乘积队列清空证明；K 的删除后性质是包含极小。第二阶段不同初始语义下的 H=6 全子集 oracle 也得到相同 4 个成员，但本阶段不借此声称当前无限模型的全局最小基数。

## 定理六：固定前驱的真实矩阵链定价可由资源化区间 DP 精确求解

**状态：已严格纸面证明；n≤9 与全 Catalan 枚举 100%交叉验证。**

固定旧树 `S`、更新叶 `i` 和内存预算。对目标树 `T`：

- `S,T` 共有且不含 `i` 的区间成本为 0；
- 其他目标区间的重算工作、读取和写入仅依赖该区间的根分裂；
- 目标持久内存是所有目标内部区间输出大小之和；
- 迁移峰值为旧缓存总量与目标缓存总量的较大值。

对每个区间保存 `(目标内存,最小加性成本,树证书)` Pareto 前沿。根处分裂枚举和左右前沿卷积覆盖且只覆盖全部合法括号树；同一内存下保留最小加性成本以及二维支配删除不会移除未来可能更优的组合。根部再加 `max(source_memory,target_memory)` 并施加预算，即得全局最优目标树。

复杂度是伪多项式，取决于 Pareto 前沿大小；不是一般未来势能下的多项式定价。n=64 两轮实验虽不枚举全树，但生成 5.64 亿个中间 DP 组合，说明该方向仍有严重规模瓶颈。

## R 与 K 严格分离

**状态：构造性严格结果。**

- `small_R_large_K.json`：6 个任务各自只有一个零成本执行架构，标量最优函数恒为 0，所以 `|R|=1`；要对全部任务保持 0，必须保留全部 6 个架构，故 `|K|=6`。
- `small_K_large_R.json`：真实二树矩阵实例中 `|K|=2`，但未来行为控制需要 `|R|=17`。

因此 R 与 K 既不能混同，也不存在普遍的单向大小界。
