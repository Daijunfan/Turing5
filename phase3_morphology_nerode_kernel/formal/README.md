# Lean 4 形式化范围

`MorphResidual.lean` 给出以下结论的 Lean 4 候选形式化：一旦历史被映射为同一个规范化残差控制状态，确定性残差控制器对任意未来任务后缀产生完全相同的逐步增量、累计增量和最终控制状态。

当前机器没有 Lean，固定版本官方工具链约 518 MB，下载连接在实测中持续低于 10 KB/s 后中止。因此本阶段**不把该文件称为已通过的机器证明**。所有理论结果按“纸面证明＋穷举验证”报告。即使以后成功检查，它也不是对 min-plus 确定化可判定性的重新证明，更没有形式化“所有 WFA 都有有限残差闭包”。

复现：

```bash
bash formal/check_lean.sh
```

脚本只使用项目内 `.toolchain/` 的固定 Lean `v4.30.0`；工具链不存在时明确输出 `SKIP`，不会在一键复现中隐式下载大文件。
