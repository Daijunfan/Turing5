# MORPH 第二阶段：迁移完备形态核研究报告

## 结论先行

第一代 PCME 的静态 Pareto 裁剪存在可复现的动态不完备性。第二阶段实现的 TCMK/CE-TCMK 在已声明的精确域内能恢复全状态动态最优；更重要的是，这一现象在真实“更新叶矩阵—失效区间—复用中间结果—重算目标区间”模型中仍然存在，不是 split-distance 人工模型独有。

当前最强的真实模型证据为：

- 维度 `(1,2,4,1,6,6)`、更新串 `(0,4,4,2,4,2)`；
- 14 个全 Catalan 状态的离线最优代价为 `594`；
- 旧静态 Pareto 核代价为 `738`，误差 `144`；
- CE-TCMK 在全部 5 个更新字母、Horizon≤6 上得到 4 状态核；
- 穷举 14 个状态的全部子集也得到同一 4 状态基数最小核；
- 该核在成对残差 oracle 中最大误差为 0。

这证明了“静态被支配、但对迁移路径有价值的桥梁形态”在真实复用模型中存在。不过，本报告不声称已经解决任意 e-graph，也不再使用“接近全局离线最优”这一旧结论：所有在线算法一律直接与当前实验状态全集的精确离线 oracle 比较。

## 1. 第一代反例精确复现

新实现没有导入或调用旧 PCME 枚举、剪枝或动态 DP 代码。独立枚举得到 42 棵 Catalan 括号树，静态 Pareto 集恰为：

| 形态 | work | peak |
|---|---:|---:|
| `A(B((C(DE))F))` | 220 | 60 |
| `(A(B(C(DE))))F` | 129 | 64 |
| `(AB)((C(DE))F)` | 128 | 67 |

桥梁 `A((B(C(DE)))F)` 为 `(221,60)`，被第一行静态支配。旧语义（仅为回归而允许首状态免费）下：

- 全 42 状态：`11628/5 = 2325.6`；
- 静态核：`12488/5 = 2497.6`；
- 差：`172`；
- 相对差的精确有理数：`21500/2907%`；
- 第一代二进制浮点显示：`7.395940832473341%`。

需要指出一个原报告未区分的数值细节：`21500/2907` 的十进制展开从 `7.395940832473340213...` 开始；题设末位 `...341` 是先用二进制浮点表示 2325.6 和 2497.6 再计算产生的显示。实现同时保存精确分数和旧显示，但所有等价判断只使用有理数。

修复后的 oracle 不允许免费首状态。`initial_state=None` 表示虚拟 source，模型必须给出 source 到首架构的构造成本；也可传入显式初始架构。`legacy_free_initial=True` 只出现在隔离的反例回归测试中。

## 2. 全状态与求值顺序

`morphology.py` 能枚举：

1. 所有保持叶序的 Catalan 满二叉树；
2. 每棵树所有递归左右求值顺序。

旧 split-distance 模型中，同一树的求值顺序不改变工作量和分裂集合，只改变临时峰值；因此精确选择最小峰值顺序会弱支配该树的其他顺序，安全合并。测试对每棵树显式枚举全部顺序后重新验证这一点。

真实持续物化模型中，长期状态是“树 + 全部内部区间结果”。同一树的不同构建顺序产生相同区间键、相同模素数矩阵值和相同持久状态；每次迁移又在边上精确优化合法拓扑执行顺序。因此求值顺序是迁移证书的一部分，而不是需要长期区分的架构状态。这是按模型语义证明后的合并，不是默认忽略顺序。

## 3. 精确动态 oracle 与在线基线

统一接口将每个任务分为：

- `service_cost(e,h)`；
- `transition_cost(e,p,h)`，其中 `p=None` 是 source。

离线 oracle 用 min-plus DP 计算完整路径和精确代价。实现同时包含：

- 全状态离线 oracle；
- 静态 Pareto 子集 oracle；
- 最佳固定架构；
- 瞬时服务最优；
- 迁移贪心；
- MCS；
- WFA。

WFA 入口会检查模型是否明确声明任务无关的度量迁移。split symmetric-difference 回归模型满足；真实叶更新模型的失效和边权依赖任务且通常非对称，因此结果中 WFA 为 `null/not applicable`，不声称理论保证。

真实桥梁轨迹上的在线/离线结果：

| 算法 | 代价 | 相对全状态离线 oracle | 切换数 |
|---|---:|---:|---:|
| 全状态离线 | 594 | 1.0000 | 1 |
| 最佳固定 | 613 | 1.0320 | 0 |
| 瞬时最优 | 1716 | 2.8889 | 0 |
| 迁移贪心 | 627 | 1.0556 | 0 |
| MCS | 627 | 1.0556 | 0 |
| WFA | 不适用 | — | — |

## 4. TCMK、桥值与 CE-TCMK

分离 oracle 同步推进全状态和候选核的 min-plus 代价向量。每步分别减去向量最小值，并把“两条规范化向量 + 最小值差”作为残差键；完全相同的键安全合并。搜索逐深度覆盖全部可达残差，不枚举重复任务前缀。

CE-TCMK：

1. 从旧静态 Pareto 集开始；
2. 找最大 `OPT_K-OPT_H` 及反例；
3. 提取全状态最优路径中的缺失状态；
4. 对每个缺失状态计算 `Bridge_H`；
5. 加入桥值最大的缺失状态；
6. 无反例后逐状态删除，每次重新做完整等价检查。

真实 14 状态实例的三轮加入为：

| 轮次 | 最大差 | 反例更新串 | 加入状态 | Bridge |
|---|---:|---|---|---:|
| 1 | 482 | `0,2,2,2,2,2` | `((AB)C)(DE)` | 62 |
| 2 | 158 | `0,0,0,0,0,0` | `(A(BC))(DE)` | 136 |
| 3 | 14 | `0,2,3,4,3,2` | `(((AB)C)D)E` | 14 |

最终核还包含初始静态状态 `((A(BC))D)E`，共 4 状态。全部子集最小核 oracle 返回完全相同集合。

理论证明见 `THEORY_ZH.md`：静态 Pareto 不安全；有限 `H/E/Horizon` 下 CE-TCMK 至多添加 `|H|-|K0|` 次；桥值给出任意排除核动态误差的下界。

## 5. 五种裁剪方法对照

同一真实实例、全部更新字母、Horizon 6：

| 方法 | 状态数 | 最大动态误差 | 完备 |
|---|---:|---:|---|
| 静态 Pareto | 1 | 482 | 否 |
| 服务 + 静态锚点迁移 Pareto | 1 | 482 | 否 |
| 严格安全块上下文规则 | 14 | 0 | 是，但无压缩 |
| CE-TCMK | 4 | 0 | 是 |
| 全子集最小核 | 4 | 0 | 是 |

题设建议的“每个 `(p,q,e)` 可选择不同 `y`”的一次上下文条件不安全。自动搜索得到三状态、两任务、最短长度 4 的连续停留反例，全状态代价 8，删状态后为 9。实现改为一个固定 `y` 同时支配入口、连续停留和出口的充分条件，并给出按极大连续块替换的证明。该规则正确但很保守；本实例删不掉任何状态，这是必须报告的负结果。

## 6. 真实迁移模型

一次任务为 `(update_index, memory_budget)`。旧树 `T` 与目标树 `T'` 都物化所有内部区间乘积。替换叶 `A_i` 后：

- `T` 中所有包含 `i` 的区间失效；
- `T` 与 `T'` 共有且不含 `i` 的区间可复用；
- 目标树其他区间按依赖拓扑重算；
- 非复用旧区间在重算前释放；
- 记录标量乘法工作、读取字节、写入字节和峰值驻留内存。

默认精确标量代价为：

`work + read_bytes/8 + write_bytes/8 + peak_bytes/8`，

同时 `peak_bytes <= memory_budget` 是硬可行性条件。所有项均用整数/有理数计算。

每次计划输出：`reused_intervals`、`invalidated_intervals`、`recomputed_intervals`、`execution_order`、`released_intervals`、`peak_memory`、`total_work`、`read_bytes`、`write_bytes`。

小状态空间使用子集 DP 枚举全部合法拓扑计划。当前“所有目标区间最终必须持续物化”的模型还允许一个闭式证明：先释放所有非复用旧区间后，工作和 I/O 与拓扑序无关，峰值恰为旧缓存和目标缓存总量的较大者；测试把子集 DP 结果与闭式独立重算逐项比较。超过阈值而使用贪心拓扑序的原始规模结果仍保守标为上界，没有借该证明篡改已经记录的实验标签。

独立 checker 不调用 planner，而是重新计算集合、依赖、工作、字节和峰值。核心实验执行 1000 次连续随机真实矩阵更新：

- 版本数 1000；
- 独立证书检查 1000/1000；
- 精确迁移计划 1000/1000；
- 每步与从头左折叠比较 1000/1000；
- 丢更新、重复更新、错误复用和数值不一致均为 0。

## 7. 实验结果

### 7.1 小规模完整枚举

split-distance 回归域完整枚举维度值 `{1,2,3,4}`、全部 Catalan 树、全部不同树峰值预算、显式 source 和 Horizon≤6：

- n=2..4：1344 个维度实例，49,316 个可达残差状态，且每例穷举真正最小核；
- n=5：4096 个维度实例，424,804 个可达残差状态；
- 合计 5440 个实例，动态等价失败 0。

这只验证 TCMK/残差算法，不作为最终真实性证据。

真实迁移模型另对同一维度网格枚举全部树、所有更新叶、Horizon≤6；每个精确迁移峰值都作为边可行性阈值检查。为控制残差字母表，动态序列使用非约束预算，未把所有预算与所有更新交叉成任务串。完整计数见 `results/real_small_exhaustive_n5.json`。

- 维度实例：5440；
- 可达成对残差状态：2,279,080；
- 不同峰值阈值上的边可行性检查：38,585,476；
- 动态等价失败：0；
- 有 126 个 n=5 实例的完备核等于 14 状态全集，说明 CE-TCMK 并非总能压缩，这一负结果没有被过滤。

### 7.2 扩展验证

n=6..10 共 10,000 个随机或对抗维度实例，保存一个主种子和全部 10,000 个实例种子。每例使用明确的 5 状态局部结合重写图、两个热点更新字母和 Horizon 6；检查阶段切换、单热点、周期热点、对抗切换以及随机热点：

- 精确动态等价轨迹：1,000,000；
- 不一致：0；
- 核大小分布：1 状态 4458 例，2 状态 3974 例，3 状态 1354 例，4 状态 209 例，5 状态 5 例。

这些比较对每例的显式 5 状态全集是精确的，但不是 n=6..10 全 Catalan oracle。该限制记录在结果文件中，不用局部候选图结果支持全局完备结论。

### 7.3 可扩展压缩族与公平运行时间

真实单热点更新族、全部任务串 Horizon≤6：

| n | 全树状态 | TCMK | 比例 |
|---:|---:|---:|---:|
| 4 | 5 | 1 | 20.00% |
| 5 | 14 | 2 | 14.29% |
| 6 | 42 | 2 | 4.76% |
| 7 | 132 | 2 | 1.52% |
| 8 | 429 | 2 | 0.47% |

因此在一个多实例、随 n 扩展的真实模型族上超过 5 倍精确压缩，而不是只依赖手工反例。

n=7、132 全状态、5 条长度 50 的优化查询：

- 全状态总时间：14.346 秒；
- 构核：3.351 秒；
- 构核加全部核查询：3.354 秒；
- 把构核全部计入后加速：4.277 倍。

### 7.4 n=16/32/64

不能枚举全树时，从左折叠、右折叠、平衡树和随机树出发，用局部结合旋转生成最多 128 状态候选图。结果与小规模全树严格分开：

- n=16：候选核 1/128，迁移标为精确；
- n=32：候选核 2/128，迁移标为启发式上界；
- n=64：候选核 2/128，迁移标为启发式上界。

这里只能说明候选图内的压缩和工程可运行性，不能说明全 Catalan 空间完备。

## 8. 成功标准与失败条件审计

| 项目 | 状态 | 证据或限制 |
|---|---|---|
| 7.395940832473341% 旧显示复现 | 通过 | `results/counterexample.json`，同时保存精确分数 |
| 声明精确域内 TCMK 对全状态 100% 一致 | 通过 | 真实 14 状态、真实完整小网格、split 完整网格；均为 0 失败 |
| 连续实际矩阵结果 100% 等于参考 | 通过 | 1000/1000 |
| 所有证书独立重算 | 通过 | 1000/1000；测试还逐项比较闭式 totals |
| 至少 5 倍精确压缩 | 通过 | n=4..8 真实热点族 |
| 优化器至少 2 倍，计构核 | 通过 | 4.277 倍 |
| 最终现象在真实复用模型存在 | 通过 | 594 对 738 的真实桥梁实例 |
| n=6..10 的 10,000 实例和百万检查 | 有范围限制地通过 | 对显式 5 状态候选图精确，不是全 Catalan |
| n=16/32/64 全局结论 | 未声称 | 仅局部图；n=32/64 为上界 |

必须报告的失败条件：

- CE-TCMK 在已完成精确域中未遗漏全状态最优路径；若今后任一残差差值非零，代码将直接判失败；
- 核没有在所有非平凡实例上接近全集：真实热点族 n=8 为 2/429；但严格安全上下文规则在真实桥梁实例上确实退化为全集；
- “真实模型下静态 Pareto 已足够”被 594 对 738 反例否定；
- 原建议上下文裁剪规则确实存在反例，已报告并替换为更强的安全充分条件；
- 大规模加速没有省略构核，计入后仍为 4.277 倍；
- 尚未完成 n=6..10 全 Catalan 的 10,000 实例验证，也没有任意 e-graph 结论。这是当前研究范围限制，不得由局部候选图结果外推。
