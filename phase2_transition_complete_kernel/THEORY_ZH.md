# TCMK 理论边界与相关工作定位

## 1. 对象定位

固定有限架构集 `H`、有限任务字母表 `E`、初始状态 `h0` 和时域 `L`。每个任务字母在架构之间给出一个精确的 min-plus 转移矩阵；矩阵元素已经包含该步的服务成本与迁移成本。于是一个任务串的最优代价是 tropical/min-plus 加权自动机的最小路径权。

TCMK 不是一个新的通用自动机模型。它是下面这个受限问题的程序重写实例：

> 在不合并状态、不改变转移权、只允许删除原架构状态的条件下，寻找一个子自动机，使固定 source 到所有长度不超过 `L` 的输入串的最小权保持不变。

这与一般加权自动机最小化不同。后者可以合并、重加权或确定化状态，并通常要求保持所有长度输入的加权语言。Mohri 的综述把 weighted automata 的路径组合和多路径汇总明确表述为半环运算，并讨论确定化、权重推动和最小化；TCMK 的规范化残差搜索与其中的 tropical residual/determinization 思想密切相关，但“保留原程序形态的最小子集”是额外结构约束。[Mohri, *Weighted Automata Algorithms*](https://research.google/pubs/weighted-automata-algorithms/)

## 2. 静态 Pareto 裁剪不保持动态最优

**命题 1。** 存在矩阵链、任务串和正迁移成本，使某形态 `x` 在 `(work, peak)` 上被另一形态严格或弱支配，但删除 `x` 会严格提高离线动态最优。

**证明。** 取维度

`(16,4,1,1,12,1,3)`，预算串

`(96,64,60,64,208,96,96,240,208,220,64,60)`，

以及第一代回归距离 `beta=4`。独立枚举 42 棵树得到：

- `A(B((C(DE))F))`: `(work,peak)=(220,60)`；
- `A((B(C(DE)))F)`: `(221,60)`。

因此第二个形态被第一个静态支配。全状态动态最优为 `11628/5`，并使用第二个形态；删去全部静态被支配状态后的最优为 `12488/5`。差为 `172`，相对误差的精确值为 `21500/2907%`。故静态 Pareto 删除不保持动态最优。证毕。

真实复用模型还给出独立证据：维度 `(1,2,4,1,6,6)`、更新串 `(0,4,4,2,4,2)` 上，全状态最优为 `594`，静态核最优为 `738`。因此失败并非只存在于人工 split-distance 中。

## 3. CE-TCMK 的有限终止与正确性

**定理 2。** 若 `H`、`E` 和 `L` 有限，分离 oracle 对长度不超过 `L` 的全部可达规范化残差精确，则 CE-TCMK 在至多 `|H|-|K0|` 次添加后终止，并返回一个 `L` 阶迁移完备核。

**证明。** 若分离值为零，定义直接给出完备性。若分离值为正，令 `w` 为分离 oracle 的反例串。全状态最优路径不可能完全位于 `K`：否则该路径也是 `K` 的可行路径，从而 `OPT_K(w) <= OPT_H(w)`，与正差矛盾。因此路径至少含一个 `H\K` 状态；算法加入其中一个，故 `|K|` 严格增加。有限次后至多到达 `H`，而 `H` 对自身显然完备，所以必然终止。最后的逐状态删除每次都重新执行完整等价检查，故保持完备性。证毕。

该定理不声称 CE 的加入顺序总能得到基数最小核。实现另用全部子集穷举作为小空间基数最小性 oracle。

## 4. 成对残差搜索为何精确

对前缀 `w`，分别保存全系统和候选核到每个终态的最小代价向量 `F_w`、`K_w`。令

- `f = F_w - min(F_w)`；
- `k = K_w - min(K_w)`；
- `delta = min(K_w)-min(F_w)`。

对下一个字母做一次 min-plus 矩阵更新后，再分别规范化；新的 `delta` 加上两个规范化偏移量之差。三元组 `(f,k,delta)` 完全决定所有后缀的演化和当前误差，因此相同三元组可安全合并。有限 Horizon 下逐层遍历全部可达三元组，就等价于遍历全部任务串，但不必显式保留相同残差的多个前缀。

此处与 tropical weighted automata 的残差/确定化有直接亲缘关系，不应把它重新包装成全新的自动机理论。区别仅在于本实现同步推进“全集”和“候选子集”两台机器，并以两者最小权之差作为分离目标。

## 5. 形态桥值与动态误差

定义

`Err(K)=max_w [OPT_K(w)-OPT_H(w)]`，

其中 `|w|<=L`。则：

1. `Bridge_H(h)=Err(H\{h})`，这是定义的直接等价；
2. 对任意 `h∉K`，因为 `K⊆H\{h}`，有 `OPT_K(w)>=OPT_{H\{h}}(w)`，所以 `Err(K)>=Bridge_H(h)`；
3. 因而任一被排除状态桥值为正，足以证明 `K` 不完备；
4. 所有单状态桥值为零却不能推出任意多状态同时删除安全，因为不同状态可以互为替代。多状态删除必须重新运行成对残差检查。

## 6. 迁移上下文删除规则

题设的单次条件允许见证 `y` 随 `(p,q,e)` 变化，不能保证连续多轮停留在 `x` 时，各次替代见证之间的转移仍便宜。

实现用固定随机种子在三状态、两任务、整数代价 `0..8` 的有界空间中自动找到长度最小为 4 的反例：

- 服务向量：`c0=(4,5,1)`，`c1=(6,0,6)`；
- `d0=((0,3,0),(5,0,7),(0,1,0))`；
- `d1=((0,3,6),(0,0,8),(8,6,0))`；
- 删除状态 0，任务串为 `(1,1,0,0)`；
- 全状态路径 `(1,0,2,2)` 代价 8；删除后路径 `(1,1,2,2)` 代价 9。

原单次条件对状态 0 成立，但删除仍不安全。

**定理 3（安全块替换条件）。** 对待删状态 `x`，若存在一个固定 `y!=x`，同时满足：

1. 对所有可能的块前驱 `p`（含 source）和任务 `e`，进入 `y` 并在 `y` 服务的代价不大于进入 `x` 并在 `x` 服务；
2. 对所有任务 `e`，在 `y` 连续停留一步的代价不大于在 `x` 连续停留一步；
3. 对所有块后继 `q` 和下一任务 `e`，从 `y` 离开的迁移代价不大于从 `x` 离开；

则可安全删除 `x`。

**证明。** 把任意路径中的每个极大连续 `x` 块整体替换为同样长度的 `y` 块。条件 1 控制入口和首个服务，条件 2 逐项控制全部内部停留，条件 3 控制出口；块外代价不变。对所有块操作后得到一条不含 `x` 且不更贵的路径。故删除 `x` 不提高任何任务串的最优值。证毕。

这是严格充分条件而非必要条件；真实实例中它可能保守到不删除任何状态。实现因此把它与 CE-TCMK 和最小核 oracle 分开报告。

## 7. 与相邻领域的精确区分

- **Metrical task systems。** 经典 MTS 要求固定、任务无关的状态距离满足度量条件，任务只给各状态服务成本；工作函数算法的理论保证建立在此前提上。[Borodin–Linial–Saks, *An Optimal On-Line Algorithm for Metrical Task System*](https://doi.org/10.1145/146585.146588) 真实叶更新使失效集合和迁移边权依赖任务，通常还非对称，因此本项目只在 split-distance 回归模型上把 WFA 标为有理论前提，在真实模型中仅可作无保证经验算法，本实现默认不运行。
- **Min-plus/tropical weighted automata。** TCMK 的离线 DP 就是 min-plus 路径求值，成对残差是有界输入等价搜索；新意若存在，只能来自“状态必须是可执行、带证书的程序形态”以及真实重物化迁移结构，不能来自给已有 tropical 对象换名。
- **Weighted automata minimization。** 标准最小化可以合并和重加权状态，并关注加权语言等价；TCMK 只删原状态、保持原边权、固定 source 且只要求有限 Horizon。Mohri 还指出 tropical 确定化/最小化需要附加性质，并非任意机器都可无条件套用。[Mohri–Riley, *On the Disambiguation of Weighted Automata*](https://arxiv.org/abs/1405.0500)
- **Parametric query optimization。** PQO 早已为未知运行时参数产生多个候选计划，每个计划在参数空间某区域最优；多目标 PQO 也已求相关 Pareto 计划。[Ganguly, VLDB 1998](https://www.vldb.org/dblp/db/conf/vldb/Ganguly98.html)，[Trummer–Koch, PVLDB](https://www.vldb.org/pvldb/vol8/p221-trummer.pdf) 静态参数区域没有表达跨时刻计划切换与有状态中间结果复用成本，这正是 TCMK 额外研究的部分。
- **Dynamic rematerialization。** Checkmate 用 MILP 求张量重物化计划，DTR 研究在线逐出/重算；它们优化张量保存与重算，而本项目把完整括号树作为长期架构状态，并研究哪些树必须保留以维护所有任务串的动态最优。[Checkmate](https://arxiv.org/abs/1910.02653)，[Dynamic Tensor Rematerialization](https://arxiv.org/abs/2006.09616)
- **e-graph extraction。** equality saturation 用 e-graph 压缩等价表达式并按给定代价提取代表项；TCMK 当前故意不扩展到任意 e-graph，而是在完整 Catalan 小空间或明确标注的局部重写候选图上研究跨时刻状态子集。[egg, POPL 2021](https://doi.org/10.1145/3434304)

## 8. 尚未证明的事项

- 尚未给出最小 TCMK 计算的一般复杂性下界；
- 尚未构造“静态 Pareto 核恒定而最小 TCMK 随 n 无界增长”的严格实例族；
- 大规模局部重写图不是全 Catalan 状态空间，不能支持全局完备结论；
- 真实迁移模型的当前代价定义对应“目标树全部内部区间持续物化”，若改成只保存部分中间结果，需要重新做状态和迁移计划证明。
